## Method and limits

Inventory: `rg --files data docs/game-design ui/learn`, then extract/deduplicate HTTP(S) strings, preserving all locations. The `source_url` field name appears in prose and types as well as JSON; extraction also includes citation links next to those fields and Markdown sources. Audited the tracked snapshot rather than any unmerged accuracy-report PR. Catalog rows inherited a dataset-level citation, not an invented per-row URL. The annual OMNI shell template is recorded separately; this audit did not redownload all annual data files.

Requests used curl GET with redirects, certificate verification, 25-second timeout, 15 MB cap and a descriptive audit user agent. No timeout/size-limit failures occurred. HTML text and PDF text were examined; no downloaded source bodies are included in the repository. Web retrieval exposed content for the three curl-403 URLs, but did not supply a replacement HTTP status. Conversely, Earthdata returned curl 200 while the web tool was blocked: access differs by client. No bypass of authentication or certificate checks was used.

The result is a citation/claim audit, not a fresh validation of orbital physics, imagery, instrument capability, licensing or every mission operational status in November 2026. Source snapshots can contain historical material (e.g. Terra’s old status section). Preserve dates when reusing longevity/current-health statements. OMNI column indexing was checked against format documentation; every daily value, gap-fill and G-scale conversion was not independently regenerated. Supporting source additions above were opened for content review; their HTTP statuses are not mixed into the 37-link inventory.

Report validation: JSON parses; all 38 unique URL records have review notes; 37 request statuses sum to 34 × 200 + 3 × 403; every recorded snapshot location contains its URL. Documentation-only change; no app tests or browser gameplay rerun needed. Owners should resolve findings in their own claims/PRs and retain this dated evidence.
