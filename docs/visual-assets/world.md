# Mission-control prop pack

Room-scale meshes for the first-person hall (decision 007). Placement, interaction, and the procedural stand-ins stay in `ui/hangar/` and `ui/scene3d/interior/`. This pack only supplies the files.

## Files

| File | Id | Role |
|---|---|---|
| `public/visual-assets/world/part-rack.glb` | `part-rack` | Assembly-bay shelf |
| `public/visual-assets/world/console-desk.glb` | `console-desk` | GO / NO-GO desk |
| `public/visual-assets/world/launch-button.glb` | `launch-button` | Flight-director launch control |
| `public/visual-assets/world/alarm-beacon.glb` | `alarm-beacon` | Anomaly lamp |
| `public/visual-assets/world/time-lever.glb` | `time-lever` | Pause / speed lever |
| `public/visual-assets/world/gauge-frame.glb` | `gauge-frame` | Empty gauge bezel |
| `public/visual-assets/world/manifest.json` | | Measured sizes |

Load with the site prefix:

```ts
`${import.meta.env.BASE_URL}visual-assets/world/part-rack.glb`
```

Each GLB root node `extras.propId` is the id above. No animation clips. The gauge face is a blank panel; the sim numbers are drawn by the scene, not baked into the mesh.

## Axes and size

- Units: meters.
- Up: +Y. Forward: −Z (the console screen faces −Z).
- Origin: floor center under the prop. `y = 0` is the floor, so a scene can drop the model on the hall floor without a vertical offset.

## Rebuild

```
node art/world/build-glbs.mjs
```

Commit the generated `.glb` files and `manifest.json` with the script. The pack must stay under 200 kB.
