# Flight training asset pack (V3)

Props and mission targets for the first flight slice. The player spacecraft and Earth/Moon/Mars stay in `ui/scene3d/` (claude@ethan). This pack does not replace them.

Stable ids match claude@jamie's training route (`hurricane`, `wildfire`, `tdrs-relay` in `data/pilot-training/route.json` on `jamie-claude/pilot-training`).

## Files

| File | Id | Role |
|---|---|---|
| `public/visual-assets/flight/hurricane.glb` | `hurricane` | Observation target |
| `public/visual-assets/flight/wildfire.glb` | `wildfire` | Observation target |
| `public/visual-assets/flight/tdrs-relay.glb` | `tdrs-relay` | Relay / inspection prop |
| `public/visual-assets/flight/manifest.json` | | Measured sizes, bounds, axes |

Load on GitHub Pages with the site prefix:

```ts
`${import.meta.env.BASE_URL}visual-assets/flight/hurricane.glb`
```

Each GLB root node `extras.targetId` is the route id. No animation clips.

NASA's [3D resources](https://science.nasa.gov/3d-resources/) (for example [Terra](https://science.nasa.gov/3d-resources/terra/)) are candidates for a later reference model. They are not in this pack. A real Terra mesh must not replace the student's configurable spacecraft. [NASA media guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/).

Facts on the training route (MODIS, FIRMS, TDRS) stay with the route data and its source URLs. These models are classroom markers for those lessons, not replicas of the storms or of a Tracking and Data Relay Satellite.

## Axes and size

- Units: meters.
- Up: +Y. Forward: −Z (the relay dish opens toward −Z).
- Origin: hurricane cloud deck on y ≈ 0; wildfire base on y = 0; relay bus centered on the origin.
- These are readable training markers, not geographic storm size and not a full-scale TDRS.

Measured 2026-11-14 (`manifest.json`):

| Id | Bytes | Triangles | Bounds min (m) | Bounds max (m) |
|---|---:|---:|---|---|
| hurricane | 2012 | 36 | −3.2, 0.15, −3.2 | 3.2, 0.4, 3.2 |
| wildfire | 1900 | 24 | −1.1, 0, −1.1 | 1.1, 3.7, 1.1 |
| tdrs-relay | 5200 | 164 | −3.5, −1.15, −1.05 | 3.5, 1.15, 0.45 |

Pack total: **9112 bytes** (under the plan's 8 MB first-flight budget). Textures: none (vertex colors via materials only).

## Rebuild

```
node art/flight/build-glbs.mjs
```

Commit the generated `.glb` files and `manifest.json` with the script so the site does not need a model-build step.
